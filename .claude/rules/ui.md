# UI Rules

## Product Character

WarungKasir is a practical POS application, not a generic SaaS dashboard.

Prioritize:

* speed
* clarity
* readability
* touch usability
* visual hierarchy

## Mobile First

Primary target:

360–430px smartphone width.

Test at:

* 360px
* 390px
* 412px

## Touch

Important buttons should have large touch targets.

Do not rely on hover interactions.

Do not use tiny icon-only controls for important actions.

## Visual Design

Primary direction:

* clean
* modern
* friendly
* professional
* minimal

Primary action color:

orange

Use restrained decoration.

Avoid generic AI-dashboard aesthetics such as excessive gradients, excessive cards, excessive glassmorphism, or decorative elements that do not improve usability.

## Cashier

The cashier flow must prioritize:

Select product
→ Cart
→ Checkout
→ Payment
→ Change
→ Complete

Do not add unnecessary steps.

## States

Every asynchronous UI must account for:

* loading
* success
* empty
* error

## Responsive

Do not introduce ordinary horizontal scrolling on mobile pages.

Verify actual browser rendering instead of assuming CSS correctness.
