# WarungKasir

Mobile-first internal POS/PWA for a single food stall.

## Users

- Owner
- Cashier

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- IndexedDB
- PWA
